# Archive branch

Local-only working material from the Assam History project, kept here so it is not lost. The website is on `main`.

- `research/` : research notes, sources and prompts (index: `research/README.md`)
- `masters/sheets/<person-id>/` and `masters/scenes/<era>/` : lossless PNG originals of the published character sheets and scenes (published copies are `media/` on `main`)
- `reels/web/` : Ahom reels (mp4 + poster, captions in `context/`); `reels/studio/` : HyperFrames projects (each has its own AGENTS.md)
