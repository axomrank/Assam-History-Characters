# Assam history character sheets

A static, offline-first library of character sheets for the people of Assam's history (Pushya Varman to
Tarun Gogoi), plus the scene gallery. Open `index.html`, or serve the folder (`python3 -m http.server`).
No build tools or internet needed to view it.

## How the data is organised

Three files are the sources of truth. Everything else is generated by `python3 tools/build.py`.

| File | What it holds | Edited by |
|---|---|---|
| `data/characters.json` | people only (names, dates, groups, summaries, sources); empty fields are dropped | `tools/merge_research.py`, `tools/import_dynasty_csv.py`, or by hand |
| `data/sheets.json` | one row per image made for a character (sheets, portraits, poses) | `tools/add_sheets.py`, `tools/import_gallery_portraits.py` |
| `catalog.json` | the 265 catalogued scenes | you |

Generated (do not edit): `data/site.js` (what the site loads), `data/availability.json`,
`data/image_availability.csv`.

## Image availability

Worked out by the build from files that exist on disk, in four levels:

| Level | Meaning |
|---|---|
| 3 sheet | a real sheet: turnaround, face, costume, props or palette |
| 2 portrait | a portrait or pose, but no sheet |
| 1 scenes | appears in catalogued scenes only |
| 0 none | nothing yet |

Scenes are split into **main** (the person is named in the scene title) and **background** (linked only by
the catalogue's ruler/figures fields). Identical image files count once. Missing files are reported as errors.
`data/image_availability.csv` lists every character with its level, counts, up to six reference scene ids,
and a next step. Open it in a spreadsheet to plan what to commission.

## Add character sheets
1. Put images in `incoming/`, as `incoming/<character-id>/<kind>.png` or `incoming/<character-id>__<kind>.png`.
   Kinds: `turnaround`, `face`, `costume`, `props`, `palette`, `pose`, `portrait`, `other`.
   `index.html#/coverage` lists every id.
2. Run `python3 tools/add_sheets.py` (add `--dry-run` to preview). It writes a 2000px WebP and a thumbnail
   to `sheets/<id>/`, keeps your original in `sheets_src/<id>/`, adds a row to `data/sheets.json` and rebuilds.

## Add or edit a person
Edit `data/characters.json`, then run `python3 tools/build.py`. `match` lists the names used in `catalog.json`
so scenes link to the person. `brief` (appearance, costume, props, avoid) feeds "Copy reference brief".

## Research data (Pushya Varman to 1826)
- `data/Assam_Characters_350-1826.csv`: every researched character, with image availability.
- `data/Ahom_kings_41_reigns.csv` and `data/Koch_kings.csv`: the Ahom reigns (Tai and Hindu names) and every Koch ruler.
- `tools/research_pre1826.py` holds the researched entries with sources and confidence; edit it, then run
  `python3 tools/research_pre1826.py && python3 tools/merge_research.py && python3 tools/export_csv.py`.
- Kamarupa rulers come from `data/sources/Assam_Dynasties_Chronological_Timeline.csv` via `tools/import_dynasty_csv.py`.

## Files
- `index.html`, `app.css`, `app.js`: the site (hash routes `#/`, `#/characters`, `#/c/<id>`, `#/kings`, `#/timeline`, `#/scenes`, `#/coverage`, `#/about`)
- `tools/common.py`: shared paths and the compact file shapes
- `images/`, `thumbnails/`: scene images as web-sized WebP; `sheets/`: web-sized character images
- `data/sources/`: the source CSVs (dynasty timeline, the original character list)

## Scene images
Scenes are stored as WebP (up to 1600px). To add new PNG scenes, list them in `catalog.json`, then run
`python3 tools/optimize_scenes.py && python3 tools/build.py`. The originals are moved to `../AHOM_archive/`,
which also holds the retired review tools and unrelated extras. That folder is not part of the published site.

## Design
Historical minimalism taken from Assamese manuscript painting: sanchi-pat bark paper, lampblack ink,
hengul (vermilion) as the one accent and haital (orpiment yellow) to mark which characters have images.
Type is Tiro Bangla for both Latin and Assamese script, loaded from Google Fonts with local serif fallbacks.
The site follows the system light or dark setting.
