# Remaining-community attire reference downloads

57 distinct image files downloaded and visually screened, organized in 24 community folders under `images/references/present-day-attire/`.

Authoritative file/source/credit records: `manifest.csv` and `manifest.json`. Raw collector manifests are historical search logs; some rejected or duplicate paths in those logs no longer exist. Reference-based character sheets were generated in a separate task and are recorded under `research/image-library/prompts/present-day/character-sheets/remaining-references-batch-*.json`.

These are local reference files. Keep each original author/licence/source record with the image; unspecified rights are not permission to publish. References from outside Assam are comparative, not automatic evidence of Assam-specific dress.
