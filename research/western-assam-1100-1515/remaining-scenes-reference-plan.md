## Reference roles

Each scene will have a small reference pack: the actual named character sheet(s), an appropriate costume comparison for supporting people, an environment reference, and only the necessary object references. A generated sheet controls creative continuity; it is not historical evidence. A modern community dress reference supplies a proposed visual direction, not proof of medieval dress or a standard ethnic face. Archaeology supplies particular surviving features, not a complete reconstructed city.

Use current published character sheets as the default selection, not superseded drafts. Preserve the user-directed Khen costumes and physiques, including the orange/green outfits shown on current sheets. Do not silently redesign their closures or garments in scene prompts. Named faces should remain distinct from generic supporting characters.
