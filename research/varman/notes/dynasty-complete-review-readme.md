# Varman dynasty — complete character review set

Thirteen sheets in dynastic order. Pushyavarman v2 and Samudravarman v1 are the existing sheets; ten further kings were generated for this request. Balavarman I and Kalyanavarman use revised v2 sheets with distinct identities. Earlier over-similar drafts are excluded.

Open index.html for the visual gallery. Each PNG contains four body views and four head views. All are modern artistic reconstructions, not authenticated portraits. Ages, body shapes, facial hair and individual dress choices were invented for differentiation, including changes from the preliminary design plan following the user’s correction. The research dossier retains the historical uncertainty.

Generator: built-in image generation tool. Exact prompts for the ten new sheets are saved alongside them; prompts for the original two are copied from their version directories. No image-generation API key or CLI fallback used.

Bhaskaravarman added as sheet 13: user-provided Bishnu Rabha facial reference, grand mukut and imperial attire. Deliberately interpretive regalia; review pending. See 13_bhaskaravarman_design_notes.md.
